{% translate "Para pihak" %}

{% translate "Perjanjian ini berlaku antara yayasan/sekolah pelanggan (Pengendali Data) dan PT Astra Digital Solusi, penyedia EduCore (Pemroses Data). Salinan yang ditandatangani menjadi lampiran kontrak berlangganan setiap yayasan dan mengikat secara hukum sejak tanggal aktivasi akun." %}

{% translate "Ruang lingkup pemrosesan" %}

{% translate "Aspek" %}{% translate "Ketentuan" %}
{% translate "Subjek data" %}{% translate "Siswa, orang tua/wali, dan staf yayasan" %}
{% translate "Kategori data" %}{% translate "Identitas, kehadiran, akademik, keuangan, kepegawaian, dan (opsional) biometrik/kesehatan" %}
{% translate "Tujuan" %}{% translate "Semata-mata untuk menjalankan layanan EduCore sesuai instruksi tertulis yayasan" %}
{% translate "Durasi" %}{% translate "Sepanjang masa berlangganan, ditambah periode retensi statutori yang berlaku" %}

{% translate "Kewajiban EduCore sebagai pemroses" %}

{% translate "EduCore memproses data pribadi hanya berdasarkan instruksi terdokumentasi dari yayasan, menjaga kerahasiaan data, menerapkan enkripsi TLS 1.3 saat transit dan AES-256 saat tersimpan, membatasi akses staf internal secara terbatas waktu dan teraudit, serta membantu yayasan memenuhi permintaan hak subjek data dan kewajiban pelaporan insiden dalam waktu 3×24 jam sejak insiden terdeteksi." %}

{% translate "Subpemroses pihak ketiga" %}

{% translate "Daftar subpemroses (mis. penyedia infrastruktur cloud, gateway pembayaran, penyedia WhatsApp Business API) dipublikasikan beserta tujuan dan lokasi pemrosesannya. Penambahan subpemroses baru memerlukan penilaian dampak pelindungan data (DPIA) terdokumentasi sebelum diaktifkan." %}

{% translate "Hak yayasan sebagai pengendali" %}

{% translate "Yayasan berhak meminta audit kepatuhan, salinan log akses ke data pribadinya, dan bukti pemenuhan kewajiban keamanan. Yayasan tetap menjadi satu-satunya pihak yang berwenang menginstruksikan perubahan tujuan pemrosesan." %}
