Autentikasi

Setiap permintaan membawa key-id di header dan tanda tangan HMAC-SHA256 atas timestamp + method + path + body. Secret tidak pernah dikirim. Permintaan dengan timestamp lebih dari 300 detik ditolak.

X-EduCore-Key-Id:    ak_live_7Qp2R9
X-EduCore-Signature: t=1789632650,v1=9f...
Idempotency-Key:     4f0a1b2c-...
AturanKetentuan
CakupanDitetapkan yayasan, per domain dan per sekolah. Tidak bisa diperluas oleh mitra.
RotasiDua kunci aktif maksimal 30 hari. Kunci lama jadi read-only saat hari ke-23.
IP allow-listOpsional per kunci, wajib untuk cakupan payroll.write.

Versi & deprekasi

Versi ada di path, bukan header. Perubahan yang memutus kontrak selalu menjadi /api/v2/ baru; penambahan field opsional bukan perubahan yang memutus. Versi lama hidup 12 bulan setelah pengganti keluar, dan mengirim header Sunset sejak hari pertama.

Format uang adalah string dengan mata uang di level objek yang sama. Jangan pernah menjumlahkan lintas mata uang: endpoint agregat mengembalikan array total per mata uang, bukan satu angka.

Error

Semua error adalah RFC 9457 application/problem+json. Cabangkan logika pada code — string SCREAMING_SNAKE yang stabil — bukan pada prosa detail.

{
  "type":     "/errors/scope-denied",
  "title":    "Scope not granted",
  "status":   403,
  "detail":   "Key lacks payroll.write",
  "instance": "/api/v1/partner/_",
  "code":     "SCOPE_DENIED"
}

Webhook & polling

Webhook adalah jalur utama. Daftarkan satu endpoint HTTPS per lingkungan, terima POST bertanda tangan sama seperti permintaan keluar, dan balas 2xx dalam 5 detik. Kegagalan dicoba ulang lima kali dengan jeda eksponensial hingga 6 jam; setelah itu kejadian tetap tersedia lewat polling.
