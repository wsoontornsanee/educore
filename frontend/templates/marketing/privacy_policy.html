{% translate "Peran pengendali & pemroses" %}

{% translate "Yayasan/sekolah adalah pengendali data (data controller) atas data siswa, orang tua, dan staf yang dimasukkan ke EduCore. EduCore bertindak sebagai pemroses data (data processor) yang memproses data tersebut hanya sesuai instruksi tertulis yayasan, sebagaimana diatur dalam Perjanjian Pemrosesan Data (DPA)." %}

{% translate "Data yang dikumpulkan" %}

{% translate "Bergantung pada modul yang diaktifkan yayasan, EduCore dapat memproses: identitas siswa dan orang tua/wali (nama, NISN, NIK, tanggal lahir, alamat), data kehadiran dan foto gerbang, template biometrik (opsional, dengan persetujuan terpisah), data akademik dan rapor, data keuangan dan tagihan, data kepegawaian dan jabatan staf, serta log komunikasi ke orang tua." %}

{% translate "Dasar & tujuan pemrosesan" %}

{% translate "Dasar hukum pemrosesan dicatat per tujuan (pelaksanaan layanan pendidikan, kewajiban pelaporan ke pemerintah, atau persetujuan eksplisit untuk biometrik, media, dan komunikasi pemasaran). Persetujuan diminta per tujuan secara terpisah — tidak pernah digabung dalam satu persetujuan umum — dan dicatat dengan versi serta waktu." %}

{% translate "Keamanan & lokasi data" %}

{% translate "Seluruh data produksi — basis data, penyimpanan objek, cadangan, dan log — berada di pusat data Indonesia, tanpa replikasi lintas negara. Data terenkripsi TLS 1.3 saat transit dan AES-256 saat tersimpan, dengan kunci enkripsi terpisah untuk PII umum, template biometrik, dan data kesehatan/konseling. Akses staf EduCore ke lingkungan produksi dibatasi waktu, disetujui, dan tercatat — tidak ada kredensial produksi yang berlaku permanen." %}

{% translate "Hak subjek data" %}

{% translate "Orang tua/wali dan staf dapat mengajukan permintaan akses, koreksi, penghapusan, pembatasan pemrosesan, atau portabilitas data melalui admin sekolah. Permintaan yang sah dilayani dalam 30 hari, kecuali data yang wajib dipertahankan sesuai kewajiban retensi statutori (lihat" %} {% translate "halaman retensi data" %}).

{% translate "Data anak" %}

{% translate "Pengaturan berbagi data siswa secara default menggunakan opsi paling ketat. Perluasan akses (misalnya berbagi data ke pihak ketiga baru) hanya dapat dilakukan lewat tindakan eksplisit admin sekolah dan selalu tercatat dalam jejak audit." %}

{% translate "Insiden kebocoran data" %}

{% translate "Dugaan kebocoran data pribadi ditangani melalui prosedur insiden internal dengan jam notifikasi 3×24 jam kepada yayasan terdampak, disertai bukti kejadian dan daftar subjek data yang terpengaruh." %}
